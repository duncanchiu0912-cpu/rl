# 課伴 Classmate｜上課小幫手

一個以繁體中文打造的學生課堂管理儀表板，純 HTML、CSS 與 JavaScript，無需安裝相依套件。

## 使用方式

直接在瀏覽器開啟 `index.html` 即可使用。可部署至 GitHub Pages 或任何靜態網站服務。

## 功能

- 每週課表瀏覽與每日課程檢視（附示範課程資料）
- 新增與勾選作業／考試待辦，使用瀏覽器 `localStorage` 保存
- 隨機抽籤點名
- 25 分鐘專注計時器，可開始、暫停與重設
- 校園公告、今日摘要與行動版側邊導覽

目前課程、公告及個人資料均為示範內容；尚未串接學校系統或雲端帳號。
